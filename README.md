# MIDOSIS

Guía de dosis de insulina (NPH y RAPI) como app web instalable (PWA). Funciona sin internet una vez instalada.

- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`, `fonts/`: la app.
- `registro-familiar/`: script de Google Apps Script y guía para guardar cada dosis en una planilla compartida y avisar por mail a la familia.
- `LEEME.md`: cómo publicarla e instalarla en el celular.

Herramienta solo informativa: no reemplaza las indicaciones del equipo médico.
